"Falar é fácil, me mostre o código"

Frase dita pelo Linus Torvalds

Os comandos Git permitem interagir com o sistema de controle de versão para gerenciar repositórios e acompanhar alterações no código. Com eles, você cria, modifica e sincroniza repositórios entre o ambiente local e repositórios remotos, deixando o fluxo de trabalho mais organizado.

Comandos Básico

Comandos Uso
git init Cria um repositório Git em um diretório vazio ou inexistente.
git clone [url] copia um repositório remoto existente para o seu computador.
git status mostra o estado atual do repositório (arquivos modificados, não rastreados ou preparados).
git add [arquivo] ou git add . adiciona arquivos à área de preparação (staging) para o próximo commit.
git commit -m salva as alterações preparadas no histórico local com uma mensagem descritiva.
git log Exibe o histórico de commits do repositório
git push envia os commits locais para o repositório remoto (como o GitHub).
git pull baixa e integra as alterações do repositório remoto para o seu ambiente local.
